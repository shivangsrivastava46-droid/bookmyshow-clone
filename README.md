# 🎬 BookMyShow Clone — Frontend

A modern and responsive **BookMyShow-inspired movie and entertainment booking frontend** built using React and Vite.

This project recreates the core user interface and experience of a movie/event booking platform, including movie discovery, search UI, authentication screens, categories, and responsive layouts.

## 📌 Features

### 🏠 Home Page
- Modern BookMyShow-inspired navigation bar
- Search bar for movies, events, plays and sports
- Location selector
- Hero/banner section
- Recommended movies section
- Movie cards with posters and genres
- Explore categories
- Promotional entertainment banner
- Responsive footer

### 🔐 Authentication
- User Signup page
- User Login page
- Form validation
- Login state management using browser LocalStorage
- Displays logged-in user's name
- Logout functionality
- Automatic navigation between Login, Signup and Home

### 🎭 Entertainment Categories
- Movies
- Live Events
- Sports
- Plays

### 📱 Responsive Design
The interface is designed to work across:
- Desktop
- Laptop
- Tablet
- Mobile devices
